# Coldfar Interactive Notebooks

This is a maintained fork of the archived Microsoft Polyglot Notebooks extension and .NET Interactive integration. Its supported path is F# notebooks with Deedle; other languages and legacy Polyglot Notebooks features are not guaranteed.

The fork uses its own VS Code extension identity, `ingted.coldfar-interactive-notebooks`, so it is not associated with the deprecated Marketplace package.

## Requirements

- Visual Studio Code 1.87 or newer
- .NET SDK 10
- The matching `Microsoft.dotnet-interactive` tool package built from this repository
